# AI QA Copilot

An AI-powered QA automation workflow that automatically generates structured test cases from Jira user stories using OpenAI and n8n.

##  Overview

AI QA Copilot helps QA engineers reduce manual effort by automating test case generation directly from Jira stories.

The workflow:

- Reads Jira user stories
- Analyzes Acceptance Criteria
- Uses OpenAI to generate structured QA test cases
- Creates an Excel test plan
- Attaches the test plan back to Jira
- Adds an automated Jira comment
